# 🌍 Flag Quiz REST API

![ASP.NET Core](https://img.shields.io/badge/ASP.NET_Core-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)
![Azure](https://img.shields.io/badge/Azure-0078D4?style=for-the-badge&logo=microsoftazure&logoColor=white)
![SQL Server](https://img.shields.io/badge/SQL_Server-CC2927?style=for-the-badge&logo=microsoftsqlserver&logoColor=white)

A REST API built with **ASP.NET Core** that serves country and flag data to a React frontend, powering an interactive flag guessing quiz.

## 🔗 Live Demo
Used in production at [braxtonplacke.com/flagquiz](https://www.braxtonplacke.com/flagquiz)

## ✨ Features
- Serves randomized flag quiz questions with multiple choice answers
- Country and flag data stored in a **SQL Server** database hosted on **Azure**
- Consumed by a React frontend for an interactive guessing experience

## ⚠️ Note
> This API is hosted on Azure's **shared (free) infrastructure**. The server may take a minute to wake up on the first request due to cold starts.
